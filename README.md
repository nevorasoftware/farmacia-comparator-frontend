# farmacia-comparator-frontend

Web Application moderna, responsive y accesible para comparar precios de medicamentos en El Salvador con referencias oficiales de la Superintendencia de Regulación Sanitaria (SRS).

## Tecnologías
- React 18
- TypeScript
- Vite
- Lucide React
- Recharts
- Vanilla CSS modular con tokens de diseño

## Variables de Entorno
- `VITE_API_URL`: URL base del backend REST (ej. `http://localhost:8080`)

## Ejecución Local
```bash
npm install
npm run dev
```
